Chatbot

Our Chatbot followed a systematic methodology to ensure the development of a robust and accurate image-based cyber attack detection system.

1. Data Collection

A diverse dataset of images representing various cyber attacks was compiled. This dataset includes high-quality images as well as more obscure, lower-quality images to simulate real-world conditions. Images were pre-processed to ensure consistency in size, resolution, and format, allowing for better model performance.

2. Model Training and Testing

The OCR model was trained using the labeled dataset. The training process involved fine-tuning a pre-trained OCR model on our custom dataset, using transfer learning to reduce the time and computational resources required. The model was evaluated using cross-validation, ensuring that it generalized well to unseen data. Metrics such as accuracy, precision, recall, and F1 score were calculated to assess performance in recognizing and extracting relevant text from images, such as phishing emails or malicious code screenshots.

3. Feature Engineering

Text-based features, such as character frequency, word patterns, and keyword analysis, were extracted from images to improve the model’s ability to distinguish between different types of cyber attacks. These textual features were then fed into the OCR model for further analysis and classification, allowing the system to more effectively detect threats based on the extracted textual content.

4. Implementation

The website was developed using HTML, CSS, and JavaScript for the frontend, while the backend was built using Python and DJANGO.
